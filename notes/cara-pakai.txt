LAB CYBER-SECURITY VERSI ANDROID (Termux)
======================================
Kamu pakai HP Android, jadi VirtualBox / Wireshark GUI / Wazuh berat TIDAK dipakai.
Penggantinya yang sudah siap:

1. Python 3.13   -> python3 --version (SUDAH ADA)
2. Nmap 7.99     -> nmap --version (SUDAH ADA, hanya scan ke lab sendiri / scanme.nmap.org)
3. dig/nslookup  -> untuk latihan DNS (SUDAH ADA)
4. proot-distro  -> untuk Ubuntu mini di HP (SUDAH INSTAL, belum download Ubuntu)
5. tcpdump       -> GAGAL instal (server root Termux down), ganti pakai latihan pcap online dulu

Struktur:
  ~/cyber-lab/scripts/ = script pertahanan (cek_log.py)
  ~/cyber-lab/logs/    = contoh log (auth-sample.log)
  ~/cyber-lab/notes/   = catatan kamu
  ~/cyber-lab/web-lab/ = latihan web defensif (nanti)

Perintah cepat Hari 1-3:
  python3 ~/cyber-lab/scripts/cek_log.py ~/cyber-lab/logs/auth-sample.log
  nmap -F 127.0.0.1
  dig google.com +short
  nslookup google.com

Aturan main: HANYA praktik ke HP sendiri / VM sendiri / situs latihan legal
seperti TryHackMe, HackTheBox, PortSwigger Academy. Jangan scan / coba akses
sistem orang lain tanpa izin tertulis.
